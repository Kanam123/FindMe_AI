About the project

Responsible AI People Search

FINDME AI is a local prototype for searching an authorized people dataset with face recognition, profile text retrieval, vector similarity, and hybrid ranking.

Baseline

Haar Cascade face detection and OpenCV LBPH recognition remain available as a clear, explainable baseline.

New AI Layer

OpenCV SFace deep embeddings are used when model files are installed. Text vectors support profile relevance ranking.

Privacy

The app is intended only for authorized or consented datasets. It does not scrape the internet or identify arbitrary strangers.
